# LESH — Лицейская Электронная Школа

JavaFX-приложение с учебными материалами и тестами по музыке для 5–8 классов.

## Что есть в версии 1.1.0

- 161 тема по учебникам 5–8 классов;
- 2 415 заданий — по 15 на каждую тему;
- 5 класс: 40 тем / 600 заданий;
- 6 класс: 48 тем / 720 заданий;
- 7 класс: 40 тем / 600 заданий;
- 8 класс: 33 темы / 495 заданий;
- типы вопросов: выбор ответа, верно/неверно, короткий ответ, открытый ответ и сопоставление;
- в списке тем показывается число заданий, а в строке состояния — общее число тем и заданий класса;
- вкладка «Видео-материалы» открывает поиск Яндекс Видео по теме;
- подсветка результатов теста и обработка ошибок загрузки;
- управление через Enter и двойной клик.

Полный перечень тем находится в `CONTENT_COVERAGE.md`.

## Требования

- JDK 21;
- Maven 3.9+ для разработки и сборки.

## Запуск из исходников

```bash
mvn clean javafx:run
```

В `javafx-maven-plugin` используется `ru.lesch.Launcher` — обычный Java main-класс, который не наследуется от `Application`.

## Сборка JAR

```bash
mvn clean package
```

После успешной локальной сборки:

```bash
java -jar target/LESH-1.1.0.jar
```

JavaFX содержит платформенные нативные библиотеки, поэтому GitHub Actions собирает JAR отдельно на Windows, Linux и macOS. В Release публикуются `LESH-windows.jar`, `LESH-linux.jar` и `LESH-macos.jar`.

## Почему исправлен GitHub Actions

В предыдущей конфигурации ручные зависимости `javafx-graphics` с `scope=runtime` и классификаторами разных ОС могли мешать Maven видеть JavaFX-классы на этапе компиляции. В 1.1.0 оставлена штатная compile-зависимость `javafx-controls`, которая подтягивает необходимые JavaFX-модули для текущей ОС, а CI выполняет отдельную сборку на каждой платформе.
