# LESH — Лицейская Электронная Школа

JavaFX-приложение с учебными материалами и тестами по музыке для 5–8 классов.

## Что есть в приложении

- выбор класса: 5, 6, 7 или 8;
- вкладка «Задания» с темами и тестами;
- вкладка «Видео-материалы» с переходом в поиск Яндекс Видео по выбранной теме;
- типы вопросов: один вариант, верно/неверно, короткий ответ, открытый ответ, сопоставление;
- подсветка правильных и неправильных ответов после проверки;
- проверка структуры учебных JSON-файлов при загрузке;
- более устойчивое поведение при ошибках загрузки контента или запуска браузера.

## Требования

- JDK 21;
- Maven 3.9+ для разработки и сборки.

## Запуск из исходников

```bash
mvn clean javafx:run
```

В `javafx-maven-plugin` используется `ru.lesch.Launcher` — обычный Java main-класс, который не наследуется от `Application`.

## Сборка JAR

```bash
mvn clean package
```

После успешной сборки:

```bash
java -jar target/LESH-1.0.1.jar
```

Shade-конфигурация включает JavaFX graphics runtime для Windows, Linux и macOS x64, поэтому JAR, собранный в CI, не привязан только к Linux как раньше.

## Управление

- выберите класс справа вверху;
- двойной клик по теме или `Enter` открывает тест;
- во вкладке «Видео-материалы» двойной клик или `Enter` открывает Яндекс Видео;
- после «Проверить ответы» карточки вопросов подсвечиваются по результату.

## Структура проекта

```text
src/main/java/ru/lesch/
  LeschApp.java
  Launcher.java
  model/
  service/
  ui/
src/main/resources/
  content/grade5.json ... grade8.json
  css/style.css
```

## Примечание по JavaFX

JavaFX содержит платформенные нативные библиотеки. Для обычного запуска из исходников Maven сам выбирает зависимости текущей ОС. Для fat JAR в проекте явно добавлены runtime-классификаторы основных desktop-платформ.
